# Roles and Permissions

## Super Administrator
- **Purpose:** Ultimate system control.
- **Responsibilities:** Manage tenants, global configs, database backups.
- **Permissions:** ALL.

## CEO
- **Purpose:** Executive oversight.
- **Dashboard:** KPI summaries, revenue vs expense, company-wide attrition risks.
- **Permissions:** Read-all across HR and Finance.

## CTO
- **Purpose:** Technical oversight.
- **Dashboard:** Engineering velocity, system uptime, cloud costs.
- **Permissions:** Tech and Security modules.

## HR Manager & HR Executive
- **Purpose:** Manage workforce lifecycle.
- **Dashboard:** Recruitment pipeline, attendance anomalies, payroll prep.
- **Permissions:** Employee CRUD, Leave Approval.

## Finance Manager
- **Purpose:** Manage company finances.
- **Dashboard:** Payroll runs, expense approvals, tax compliance.
- **Permissions:** Finance, Payroll execution.

## Project Manager & Tech Lead
- **Purpose:** Delivery orchestration.
- **Dashboard:** Sprint burndown, resource allocation.
- **Permissions:** Task assignment, sprint planning.

## Software Engineer / QA Engineer / DevOps Engineer
- **Purpose:** Execution and delivery.
- **Dashboard:** My Tasks, CI/CD status, Bug queues.
- **Permissions:** Update task status, trigger builds.

## Security Analyst
- **Purpose:** Protect infrastructure.
- **Dashboard:** Threat maps, audit logs, compliance violations.
- **Permissions:** Block users, view raw telemetry.

## Employee & Intern
- **Purpose:** Base roles.
- **Dashboard:** Personal attendance, leaves, payslips.
- **Permissions:** Read personal data, submit requests.
